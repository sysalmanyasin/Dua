# Test acceptance matrix

**Baseline:** commit `07e87e4` plus the Audit 0 branch, 27 Nov 2026. Method and results: `docs/AUDIT_0_BASELINE.md`.

**How to read it.** "Automated result" is what I ran. **A passing row does not mean the module is accepted.** Acceptance needs the automated result, the missing coverage closed or consciously waived, and, where listed, owner or device sign-off. Owner statements recorded in older documents are not re-verified here. Today the Accepted column is **No** for every row, because every row has open coverage or sign-off items.

Legend for tests: `U` = unit/jsdom file(s) in `tests/unit`; `DB` = SQL file(s) in `supabase/tests`; `H` = Edge Function handler test.
